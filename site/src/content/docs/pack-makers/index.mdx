Almost all of Farmer's Delight is data: recipes, tags, loot tables, loot modifiers, worldgen, villager trades and advancements are JSON files in the mod jar under the <code>{meta.modId}</code> namespace.
A data pack can add to them, replace them or switch them off, with no code. Everything on these pages is read from the mod's files and Java for version {meta.modVersion}.

## How overriding works

- **Replace a file:** put a file at the same path in your data pack, for example `data/farmersdelight/recipe/cooking/beef_stew.json`. Data packs above the mod in the pack list win.
- **Remove a file:** NeoForge skips any data file whose `neoforge:conditions` fail <Cite c={conditions.skip} />. A replacement with <code>{JSON.stringify({ 'neoforge:conditions': [{ type: conditions.never.value }] })}</code> turns the file off.
- **Add to a tag:** a tag file at the same path is merged with the mod's unless it sets `"replace": true`.
- **Load only with Farmer's Delight:** use NeoForge's `neoforge:mod_loaded` condition with <code>"modid": "{meta.modId}"</code> on your own files.

## For add-on authors

These registry entries are yours to use from data:

| What | Ids |
|---|---|
| Recipe types | `farmersdelight:cooking`, `farmersdelight:cutting` |
| Ingredient type | <code>farmersdelight:{itemAbility.registered.value}</code> |
| Load conditions | {conditions.registered.value.map((c, i) => <>{i > 0 && ', '}<code>farmersdelight:{c}</code></>)} |
| Loot modifier types | {lootModifiers.registered.value.map((c, i) => <>{i > 0 && ', '}<code>farmersdelight:{c}</code></>)} |
| Biome modifier type | `farmersdelight:add_features_by_filter` |
| Feature types | {biomeModifier.features.value.map((c, i) => <>{i > 0 && ', '}<code>farmersdelight:{c}</code></>)} |
| Placement modifier | <code>farmersdelight:{biomeModifier.placementRegistered.value}</code> |
| Consume effects | {consumeEffects.registered.value.map((c, i) => <>{i > 0 && ', '}<code>farmersdelight:{c}</code></>)} <Cite c={consumeEffects.registered} short /> |

The consume effects work in any item's `minecraft:consumable` component, so your own drinks can behave like Farmer's Delight's:

| Effect | Fields |
|---|---|
| `farmersdelight:remove_random_effects` | `excluded`: mob-effect tag (required), `harmful_only`: boolean (default `false`) <Cite c={consumeEffects.removeRandom} short /> |
| `farmersdelight:heal` | `amount`: float, health points (required) <Cite c={consumeEffects.heal} short /> |
| `farmersdelight:extinguish` | none <Cite c={consumeEffects.extinguish} short /> |

To make your items work with knives, cooking pots and heat, add them to the tags on [Tags](/pack-makers/tags/): for example `#c:tools/knife` for Cutting Board knife recipes, `#farmersdelight:heat_sources` for blocks that heat a pot, and `#farmersdelight:serving_containers` for containers.
