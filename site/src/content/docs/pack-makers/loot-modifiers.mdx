Farmer's Delight adds its extra drops with NeoForge global loot modifiers: {modifiers.length} files in `data/farmersdelight/loot_modifiers/`, using {lm.registered.value.length} modifier types of its own <Cite c={lm.registered} />.
They add chest loot, knife drops from animals, straw from grass and crops, pumpkin slices and pie slices. What players get is on [Loot](/mechanics/loot/) and [Knives](/mechanics/knives/); this page is about the files.

## How NeoForge loads them

- Every `.json` in any namespace's `loot_modifiers` folder is loaded; there is no list file <Cite c={lm.folder} />.
- Higher `priority` runs first; equal priorities run in no fixed order <Cite c={lm.order} />.
- A file is an id: `data/farmersdelight/loot_modifiers/straw_from_grass.json` is `farmersdelight:straw_from_grass`. A data pack file at the same path replaces the mod's.

Every modifier, whatever its type, has these fields <Cite c={lm.baseFields} />:

| Field | Type | Required | Default |
|---|---|---|---|
| `type` | modifier type id | yes | |
| `condition` | one loot condition (combine several with `minecraft:all_of`) | no | always applies |
| `priority` | int | no | <code>{lm.defaultPriority.value}</code> <Cite c={lm.defaultPriority} short /> |

## Modifier types

### farmersdelight:add_item

Adds a stack to the drops. Counts above the item's stack size are split into several stacks <Cite c={lm.addItemApply} />.

| Field | Type | Required | Default |
|---|---|---|---|
| `item` | item id | yes | |
| `count` | int | no | `1` <Cite c={lm.addItem} short /> |

<RepoFile path="src/generated/resources/data/farmersdelight/loot_modifiers/straw_from_grass.json" />

### farmersdelight:replace_item

Removes every stack of `removed_item` from the drops and adds `count` of `added_item` <Cite c={lm.replaceItemApply} />.

| Field | Type | Required | Default |
|---|---|---|---|
| `removed_item` | item id | yes | |
| `added_item` | item id | yes | |
| `count` | int | no | `1` <Cite c={lm.replaceItem} short /> |

<RepoFile path="src/generated/resources/data/farmersdelight/loot_modifiers/scavenging_pumpkin.json" />

### farmersdelight:add_loot_table

Rolls another loot table and adds its results. It does nothing while the config option `generateFDChestLoot` (default <code>{String(chestLoot.default)}</code>) is off <Cite c={lm.addTableGate} />.

| Field | Type | Required | Default |
|---|---|---|---|
| `table` (or `lootTable`) | loot table id | one of the two | <Cite c={lm.addTable} short /> |

All {chest.length} chest modifiers use it, with NeoForge's `neoforge:loot_table_id` condition to pick the chest:

<RepoFile path="src/generated/resources/data/farmersdelight/loot_modifiers/add_loot_simple_dungeon.json" />

### farmersdelight:pastry_slicing

Adds the uneaten slices of a cake or Farmer's Delight pie that is being broken: {lm.pastryBites.value.cake} minus bites taken for a cake, {lm.pastryBites.value.pie} minus bites for a pie <Cite c={lm.pastryBites} />. Other blocks get nothing.

| Field | Type | Required |
|---|---|---|
| `slice` | item id | yes <Cite c={lm.pastry} short /> |

<RepoFile path="src/generated/resources/data/farmersdelight/loot_modifiers/slicing_apple_pie.json" />

## Changing or turning off a modifier

**Chest loot:** set `generateFDChestLoot = false` in the [common config](/reference/config/#generateFDChestLoot).

**Any modifier:** put a file at the same path in your data pack.

- To change it, copy the mod's file and edit the chance, count or condition.
- To remove it, give the file a NeoForge load condition that is never true. NeoForge skips data files whose `neoforge:conditions` fail <Cite c={conditions.skip} />, and `neoforge:never` always fails <Cite c={conditions.never} />.

<Code lang="json" title="data/farmersdelight/loot_modifiers/straw_from_grass.json (in your data pack)" code={JSON.stringify({ 'neoforge:conditions': [{ type: conditions.never.value }], type: 'farmersdelight:add_item', item: 'farmersdelight:straw' }, null, 2)} />

<Aside type="caution" title="Not tested in game">
The removal recipe above follows NeoForge's loader code for 26.3.0.101; it has not been tested in a running game for these docs. The rest of the file only has to parse; it is never applied.
</Aside>
