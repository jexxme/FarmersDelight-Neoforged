## Minecraft and NeoForge versions

There is one file per Minecraft version, all with the same content, version {meta.modVersion}. The mod id stays <code>{meta.modId}</code>, so worlds and add-ons made for Farmer's Delight keep working.

Ranges use Maven notation: `[a,b)` means from `a` up to but not including `b`; `[a,)` means `a` or newer.

## Recipe viewers

| Viewer | Status |
|---|---|
| **JEI** | Supported on every version |
| **REI** | Supported on Minecraft 26.1.2 and newer (<Src path="README.md" lines="43" />) |
| **EMI** | Not yet: EMI has no 26.x release. The plugin code is kept, commented out, in `integration/emi/` |

### JEI

- Recipe categories for the Cooking Pot, Cutting Board and Organic Compost decomposition <Cite c={jei.categories} />.
- The Cooking Pot, Cutting Board and Organic Compost are their categories' stations; the Stove and Skillet are added to vanilla campfire cooking <Cite c={jei.catalysts} />.
- Click the Cooking Pot's arrow to open its recipes <Cite c={jei.clickArea} />, and move a recipe's ingredients into the pot with JEI's transfer button <Cite c={jei.transfer} />.
- Info pages for wheat dough, straw, ham, knives and the wild crops <Cite c={jei.info} />.

Known gaps: the knife info page is missing for the <Item id="copper_knife" />, and the water dough recipe is shown with two wheat <Cite c={jei.doughDisplay} /> although it takes exactly one <Cite c={doughNeedsOne} />.

### REI

The same categories, stations, click area and recipe transfer <Cite c={rei.categories} /> <Cite c={rei.clickArea} /> <Cite c={rei.transfer} />. The info pages include all six knives <Cite c={rei.info} />, and the dough recipe shows one wheat <Cite c={rei.displays} />. The REI integration is adapted from Farmer's Delight Refabricated.

## AppleSkin

Works: AppleSkin reads food values from the game, so Farmer's Delight's food shows normally. The mod has no AppleSkin-specific code. Nourishment draws its own gilded hunger bar (client option `enableNourishmentHungerOverlay`).

## CraftTweaker

Not yet: CraftTweaker has no 26.x release. The integration code is kept, commented out, in `integration/crafttweaker/`. Data packs can do everything the CraftTweaker support did; see [Recipe formats](/pack-makers/recipes/).

## Tags for other mods

Farmer's Delight fills common `c:` tags (crops, foods, seeds, tools, storage blocks…), so recipes from other mods that ask for "any onion" or "any knife" accept its items. It also adds its items to tags of these mods: {foreign.map((ns, i) => <>{i > 0 && ', '}<code>{ns}</code></>)}.
Some of its own tags list other mods' items as optional entries, skipped when that mod is missing: {optional.map((ns, i) => <>{i > 0 && ', '}<code>{ns}</code></>)}. Every entry is on [Tags](/pack-makers/tags/).

<Aside title="Coming from the original Farmer's Delight?">
Remove it first; this port replaces it. Recipe ids match Farmer's Delight 1.21, so packs and scripts that refer to them keep working. See [Differences from upstream](/differences/).
</Aside>
