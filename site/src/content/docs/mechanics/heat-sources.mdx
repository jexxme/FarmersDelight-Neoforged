A <Item id="cooking_pot" /> or a placed <Item id="skillet" /> only cooks while something hot is under it. The mod
decides that with two block tags: **heat sources**, which give heat, and **heat conductors**, which pass it up from
the block below. A placed pot or skillet checks the block under it every tick.

## How it works

The rule is short <Cite f={heat.isHeated} />:

1. If the block **directly below** is a heat source, the pot is heated. If that block has a `lit` state, it must be lit
   <Cite f={heat.directLit} />.
2. Otherwise, if the block directly below is a **heat conductor** and the block **two below** is a heat source (same lit
   rule), the pot is heated <Cite f={heat.conducted} />.
3. Nothing else counts. Heat never travels sideways, never more than two blocks, and only through one conductor.

<HeatRule />

The pot and the skillet both accept conductors: the code has a switch for "direct heat only", but no block turns it on
<Cite f={heat.requiresDirect} />.

## Heat sources

- The <Item id="stove" /> is placed already lit, so it works at once <Cite f={stove.placedLit} />. Put it out with a
  shovel or a water bucket and the pot cools down; see [Stove](/mechanics/stove/).
- Blocks in the list without a `lit` state, like <Item id="minecraft:magma_block" /> or a
  <Item id="minecraft:lava_cauldron" />, always count.
- Light level does not matter, and the source does not need to touch anything else.

## Which blocks show a tray

A pot or skillet standing on a block from `#farmersdelight:tray_heat_sources`
({trays.map((id, i) => <>{i ? ', ' : ''}<Item id={id} /></>)}) gets a metal tray under it, with a full-width
1-pixel collision box <Src path="common/block/CookingPotBlock.java" lines="57-58" /> <Cite f={heat.trayPot} /> <Cite f={heat.traySkillet} />. The tray is only looks and collision; heating
works the same with or without it.

The Stove, magma block and lava cauldron heat without a tray. A hanging pot (placed against the underside of a block)
never changes to a tray.

## The hand-held skillet is different

Cooking with a <Item id="skillet" /> held in your hand uses its own, looser check: you are near heat if you are on fire, or
if any block in the 3×3×3 cube around you is in `#farmersdelight:heat_sources`. That check looks at the tag only, so an
unlit campfire or an unlit Stove counts, and conductors play no part <Cite f={heat.heldNear} />. See
[Skillet](/mechanics/skillet/).

## Details

- Pack makers can add any block to these tags. Any block with the standard `lit` state is checked for it automatically.
- Both tags are block tags, so items and entities (a burning mob, a lava bucket) never count, except for the hand-held
  skillet, which also accepts a burning player.
- Without heat, a pot or placed skillet loses progress at {pot.decay.value} per tick rather than resetting; see
  [Cooking Pot](/mechanics/cooking-pot/#how-it-works).
