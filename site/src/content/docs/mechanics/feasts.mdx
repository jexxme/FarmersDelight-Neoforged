export const feasts = tags.resolved.block['farmersdelight:feasts'];
export const maxOf = (id) => Math.max(...blocks[id].properties.servings.map(Number));
export const servingOf = (id) => id.replace(/_block$/, '');
export const lootOf = (id) => {
	const t = loot.blocks[id.replace('farmersdelight:', 'farmersdelight:blocks/')];
	const max = maxOf(id);
	const full = t.pools.filter((p) => p.conditions.includes(`servings = ${max}`)).flatMap((p) => p.entries.map((e) => e.item));
	const part = t.pools.filter((p) => p.conditions.includes(`not (servings = ${max})`)).flatMap((p) => p.entries.map((e) => e.item));
	return { full, part };
};
export const medley = 'farmersdelight:rice_roll_medley_block';
export const fourServing = feasts.filter((id) => id !== medley);

Feasts are big meals you place as a block and share. Each one holds several servings; anyone can take a serving by
right-clicking it with the right container, usually a <Item id="minecraft:bowl" />. There are {feasts.length} feasts, all
cooked or crafted as a single item that stacks to {items['farmersdelight:roast_chicken_block'].stack}.

<Shot src="mechanics/feast-table.jpg" caption="A feast table: roast chicken, honey glazed ham, stuffed pumpkin, shepherd's pie, rice roll medley and gleaming salad, some already served, next to pies with slices taken." />

## How it works

<ServingLadder block="roast_chicken_block" />

1. **Place** the feast on top of a solid block; it needs a rigid surface below and breaks off otherwise
   <Cite f={feast.survive} />.
2. **Serve.** Right-click holding the serving's container. One container is used (not in creative), one serving goes into
   your inventory or drops, and the feast shows one serving less <Cite f={feast.take} />. Holding anything else shows a
   "use a …" hint naming the container.
3. **Leftovers.** Most feasts stay as a plate of leftovers at 0 servings; right-click the leftovers to clear them, which
   breaks the block and drops its loot <Cite f={feast.leftovers} />. The <Item id="stuffed_pumpkin_block" /> has no
   leftovers and disappears with its last serving <Cite f={feast.vanish} />.

A comparator next to a feast reads its servings left <Cite f={feast.comparator} />. Feasts break instead of moving when a
piston pushes them <Cite f={feast.properties} />.

## Breaking a feast

Breaking a feast that is **full** gives the feast back as an item. Breaking it after even one serving was taken drops only
the leftovers: the remaining servings are lost. From the loot tables:

<table>
	<thead><tr><th>Feast</th><th>Broken while full</th><th>Broken after serving</th></tr></thead>
	<tbody>
		{feasts.map((id) => {
			const l = lootOf(id);
			return (
				<tr>
					<td><Item id={id} /></td>
					<td>{l.full.map((x, i) => <>{i ? ', ' : ''}<Item id={x} /></>)}</td>
					<td>{l.part.length ? l.part.map((x, i) => <>{i ? ', ' : ''}<Item id={x} /></>) : <em>nothing</em>}</td>
				</tr>
			);
		})}
	</tbody>
</table>

## Gleaming Salad

The <Item id="gleaming_salad_block" /> glows: its light level is {feast.saladLightPerServing.value} per serving left, so
{blocks['farmersdelight:gleaming_salad_block'].maxLight} when full <Cite f={feast.saladLightPerServing} />. It sparkles with a
chance of {feast.saladSparkle.value * 100}% per serving each animation tick <Cite f={feast.saladSparkle} />.

<Aside type="note" title="How serving behaves in this version">
A feast only serves when its serving item has a container: the check is `container != null && held item is that
container` <Cite f={feast.containerCheck} />. The rolls have none
({[...new Set(feast.medleyOrder.value)].map((id, i) => <>{i ? ', ' : ''}<Item id={id} /></>)}: no crafting remainder in the
item data), so in this version right-clicking the medley with any item does not take a serving and shows no hint. Breaking
it while full returns the medley. This is read from the code and has not been checked in game.
</Aside>

## Details

- Feasts are not pathfindable, so mobs walk around them <Src path="common/block/FeastBlock.java" lines="173-176" />.
- Each serving plays the "take portion" sound and, except for the Rice Roll Medley, a few crumb particles.
- Serving counts the held container as used in your statistics.
