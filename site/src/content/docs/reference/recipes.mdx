All {meta.counts.recipes} recipes that load in a plain game: {meta.counts.cooking} for the [Cooking Pot](/mechanics/cooking-pot/), {meta.counts.cutting} for the [Cutting Board](/mechanics/cutting-board/), and the rest for crafting tables, furnaces, smokers, campfires and the smithing table.
Hover a slot for the item name; slots that cycle accept any item of a tag. The code under each card is the recipe id for data packs and `/recipe`.

To see how a recipe breaks down into raw materials, use the [recipe planner](/reference/recipe-planner/). The {meta.counts.integrationRecipes} recipes that only load with other mods installed are on [Compatibility](/compatibility/#data-only-integrations).
