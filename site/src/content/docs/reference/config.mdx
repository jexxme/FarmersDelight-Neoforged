Farmer's Delight has two config files: <code>{configFiles.common.value}</code> with {common.length} gameplay options <Cite c={configFiles.common} /> and <code>{configFiles.client.value}</code> with {client.length} display options <Cite c={configFiles.client} />.
You can also edit them in game: the mod registers a config screen for the **Mods** list <Cite c={configFiles.screen} />.

<Aside title="Keep client and server in step">
NeoForge for 26.3 dropped the "common" config type, so the port registers <code>{configFiles.common.value}</code> as a local config under its old file name; existing configs keep working <Cite c={configFiles.common} />.
Two options change item defaults at startup, `enableRabbitStewBuff` and `enableStackableSoupItems`. Their own comments ask for the same value on the client and the server.
</Aside>

Comments are copied from the code. Open **What it affects** for what the option changes and the code that reads it.
