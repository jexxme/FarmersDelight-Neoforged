export const client = config.filter((c) => c.file === clientFile && c.key !== 'enableComfortHealthOverlay');

Farmer's Delight has {common.length} gameplay settings and {client.length} settings for your own screen.
The easiest way to change them is in game: on the title screen click **Mods**, pick Farmer's Delight and click **Config**.
Most changes apply right away; the few that don't say so below.

You can also edit the files in the `config` folder of your game or server: <code>{commonFile}</code> for gameplay and <code>{clientFile}</code> for the display options.
Each setting below shows its in-game name first and its name in the file after it.

<Aside title="Running a server?">
The server's gameplay file decides almost everything. Two settings, **Rabbit Stew Buff** and **Stackable Soup Items**, change items when the game starts, so every player needs the same value as the server. Otherwise food values or stack sizes won't match.
</Aside>
